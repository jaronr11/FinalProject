Maze Crawler Game:
Controls:
- WASD -> move
- Left click -> shoot at mouse cursor
  
Gameplay:
- Player is Green slime
- Enemies are Red Slimes
- Chests contain different weapon types
- Each room has a red door that is closed. To open it and progress to the next room, you must kill all the enemies.
- Game currently only has 3 rooms. 

Design Patterns:
- Strategy: Enemy movement behaviors
- Builder: Room creation
- Factory: Creation of characters and projectiles
- Facade: Simplifies game setup
- MVC: Struture of projects/directoies, separates logic, rendering, and input
